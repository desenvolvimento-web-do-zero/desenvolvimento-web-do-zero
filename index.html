PRIMEIROS PASSOS

O que é desenvolvimento web?

É o processo de criação e manutenção de sites e aplicações web. Ele combina estrutura, design, programação e resolução de problemas para oferecer experiências úteis aos usuários.

TECNOLOGIAS PRINCIPAIS

Os três pilares da web

HTML

Cria a estrutura e organiza os conteúdos da página.

Aula 1: Introdução ao HTML

HTML significa HyperText Markup Language, ou Linguagem de Marcação de Hipertexto. Ele é utilizado para estruturar o conteúdo de páginas na internet.

Conhecendo as tags

As tags indicam ao navegador como cada elemento deve ser interpretado.

  • <h1> cria um título principal.
  • <p> cria um parágrafo.
  • <a> cria um link.

Exemplo prático

<h1>Meu primeiro site</h1>
<p> To aprendendo HTML!</p>

Nesse exemplo, criamos um título e um parágrafo para aparecerem na página.

CSS

Define cores, fontes, espaçamentos e o visual.

Aula 2: Introdução ao CSS

CSS significa Cascading Style Sheets, ou Folhas de Estilo em Cascata. Ele é utilizado para definir a aparência dos elementos de uma página web.

O que podemos fazer com CSS?

  • Mudar a cor dos textos.
  • Alterar o tamanho das letras.
  • Adicionar cores de fundo.
  • Organizar o posicionamento dos elementos.

Conhecendo uma regra CSS

h1 {
    color: blue;
    font-size: 32px;
}

Nesse exemplo, todos os títulos h1 selecionados por essa regra terão texto azul e tamanho de fonte de 32 pixels, desde que nenhuma outra regra aplicável tenha prioridade maior.

Entendendo as propriedades

  • color: define a cor do texto.
  • font-size: define o tamanho da fonte.
  • background-color: define a cor de fundo.
  • text-align: controla o alinhamento do texto.

JavaScript

Adiciona comportamentos e interações à página.

Aula 3: Introdução ao JavaScript

JavaScript é uma linguagem de programação utilizada para adicionar interatividade e comportamento às páginas web.

O que podemos fazer com JavaScript?

  • Responder aos cliques em botões.
  • Mostrar e esconder conteúdos.
  • Verificar informações digitadas em formulários.
  • Atualizar textos na página.

Conhecendo uma variável

let nome = "Maria";

console.log(nome);

Nesse exemplo, criamos uma variável chamada nome e armazenamos nela o texto "Maria". O comando console.log() permite visualizar esse valor no console do navegador.

Fazendo uma ação acontecer

const botao
  = document.querySelector
  ("#meu-botao");

botao.addEventListener
  ("click", function() {
    alert("Você clicou
  no botão!");
});

Esse exemplo localiza um botão com o ID meu-botao e mostra uma mensagem quando alguém clica nele.

Entendendo os comandos

  • let: declara uma variável cujo valor pode ser alterado.
  • const: declara uma variável que não pode ser reatribuída.
  • document.querySelector(): localiza um elemento na página.
  • addEventListener(): registra uma ação para um evento.
  • alert(): exibe uma caixa de mensagem.
